基于大语言模型工作流的智能航运单据处理系统，涵盖多格式单据OCR智能解析、表单与文档实时同步预览、动态贸易模板映射分配及多维度计费配额控制等核心功能。系统旨在解决传统航运物流行业中提单格式繁杂、人工录入效率低、校验比对困难以及商业数据高度敏感的安全合规等痛点。核心贡献与技术优化：

• 智能OCR解析与大模型工作流编排：
  • 深度集成 Dify AI API 编排解析逻辑，针对航运提单构建了专用的语义化数据智能提取方案，实现对纯图或PDF中的货主、收货人、船次等 30 多项核心字段的精准结构化提取。
  • 优化效果： 将单份复杂海运提单的平均人工录入与核对时间从 10 分钟缩短至 15 秒以内，核心字段提取准确率跃升至 98% 以上，极大释放了人工效能。

• 实时同步预览与动态模板渲染引擎：
  • 采用 Apache POI 构建底层数据合并驱动，结合前端 Vue 3 及 docx-preview 技术，实现左侧前端表单修改、右侧“所见即所得”实时生成并呈现 PDF/Docx 预览文件的交互闭环。
  • 解决痛点： 彻底解决了传统表单录入与最终流转文档生成的割裂感，实现毫秒级文档实时重渲染及回显，大幅优化了单证人员的容错校验体验与发单效率。

• 细粒度会员配额与高可靠安全权限管控：
  • 基于 Spring Boot 2.5 整合 Apache Shiro 与 Redis 实现了高灵活度、微服务友好的系统级身份鉴权与会话管控，设计了支持“按月/按次”双向计量维度的 AI 解析高并发扣量阻断机制。
  • 解决场景： 有效保障了平台类 SaaS 产品的多租户/多用户资源安全隔离，确保了在多用户并发调用庞大 AI 接口配额场景下的防超卖与计费绝对精准性。

• 自动化数据安全清洗体系与容灾策略：
  • 结合 Spring 自动化任务体系开发数据冗余“即用即焚”熔断维护策略，在系统空闲期静默定时清理服务中的 OCR 临时文件分片、用户上传缓存及无用中间态输出流。
  • 成果表现： 从物理基建层完全排除了因大规模日志与文档堆积导致的服务器 I/O 与存储溢出引发的宕机风险，同时从根源上满足了航运与跨国商业数据极其严苛的隐私安全合规诉求。
